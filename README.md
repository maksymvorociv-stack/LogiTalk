LogiTalk — це клієнт-серверний текстовий чат-застосунок з елементами персоналізації профілю та графічним інтерфейсом користувача

Архітектура проєкту
Проєкт розділений на дві незалежні частини для забезпечення стабільності та масштабованості:

server (Серверна частина):

Приймає з'єднання від клієнтів

Обробляє та маршрутизує текстові повідомлення

Зберігає дані про користувачів (аватарки, статуси) та історію листування

client (Клієнтська частина):

Графічний інтерфейс користувача (GUI)

Відображає профіль користувача з аватаркою

Містить зручне поле для введення та відправки тексту

Надсилає запити на сервер і відображає отриману відповідь у реальному часі

Основні функції
Кастомізація профілю:

Можливість вибору або зміни аватарки для ідентифікації користувача в чаті

Відображення аватарок співрозмовників біля їхніх повідомлень

Текстовий чат:

Інтуїтивне поле введення тексту

Миттєва відправка повідомлень на сервер

Відображення діалогу у вигляді стрічки повідомлень

Мережева взаємодія:

Забезпечення зв'язку між client та server через мережеві протоколи (наприклад Sockets / REST API / WebSockets)

Сфера застосування та призначення
Навчальний або практичний проєкт: Демонстрація принципів побудови клієнт-серверних систем, обробки мережевих запитів та створення графічних інтерфейсів

Особистий месенджер: Інструмент для обміну текстовими повідомленнями в локальній мережі або через інтернет

Чат-асистент: Основа для підключення чат-бота чи ШІ на боці сервера
